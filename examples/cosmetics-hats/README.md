# cosmetics-hats

Example content mod (API 0.3): three cosmetics, a gold crown and a party hat for the `hat` slot and an ember fringe
for the `hair` slot. Players need the mod loader to see them; vanilla players just see the plain vanilla look.

- `/hat <crown|party|none>` and `/hair <ember|none>` change what you wear.
- **Default.** A player who has not chosen anything for a slot yet gets that slot's default when they join: the
  gold crown for `hat`, nothing for `hair`, so a fresh player sees a cosmetic without typing `/hat`. Change the
  `DEFAULTS` table in `server/main.luau` to hand out something else (or nothing).
- **Remembered choice.** The server does not save what players wear, so the mod keeps the choice in its storage
  (`wear:<player>:<slot>`) and puts it back on every join. `/hat none` is a choice as well (stored as `none`): it
  takes the hat off and the default does not come back.

The art is generated by `art/make_art.py`.
